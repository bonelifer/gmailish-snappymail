# Gmailish for SnappyMail

A Gmail-inspired theme for SnappyMail with adaptive light and dark colors and a compact folder list.

## Installation

Use `gmailish-snappymail.css` with SnappyMail's custom CSS configuration or a user-style browser extension such as Stylus.

## Notes

- The stylesheet imports Google Sans and Roboto from Google Fonts.
- SnappyMail markup can change between releases, so some selectors may need adjustment after an upgrade.
